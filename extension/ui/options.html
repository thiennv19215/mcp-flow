Cài đặt Flow MCP Connector

Kết nối extension với backend Flow MCP trên máy tính hoặc VPS.
Thông số kết nối
VPS backend Localhost http://localhost:18899
Backend VPS cần HTTPS. Nhập mã ghép đôi do quản trị viên cấp để xác thực thiết bị Chrome này.
Mã này được đổi lấy token riêng cho profile Chrome hiện tại và sẽ được xóa sau khi ghép đôi.
Hướng dẫn nhanh
1
Khởi động server: Chạy script Start Flow.cmd hoặc lệnh npm run studio để kích hoạt server cổng 18899.
2
Mở dự án Flow: Truy cập flow.google.com, mở dự án bất kỳ và giữ tab đó đang mở.
3
Liên kết: Nhấp vào biểu tượng Extension và bấm nút "Kết nối tab Flow hiện tại" để bắt đầu điều khiển tự động.
